触发采价需要一次性授权

网页本身采不了价：斗货接口不允许浏览器跨域，密钥也不能放进公开的网页。所以「刷新」的作法是——通知 GitHub 那台免费机器去采价。为此需要你粘贴一个 GitHub 令牌。

推荐用 Fine-grained token：Repository access 只勾这一个仓库，Permissions 里把 Actions 设为 Read and write。若用经典 token，则勾选 workflow。 这样即便令牌泄露，最坏也只是能重复触发采价——读不到仓库里的密钥，也动不了其他仓库。
